Magic Manta takes a company's domain and returns that company's social profiles across X, Threads, Instagram, LinkedIn, Bluesky, GitHub and more, with the evidence behind each handle: a Verified badge when the official site declares it through Schema.org sameAs or a page link, Unverified when it came from search and does not link back to the domain. Single lookups are free, batch runs and saved lists come with a plan, and an auth-gated MCP server lets an assistant run lookups directly.
