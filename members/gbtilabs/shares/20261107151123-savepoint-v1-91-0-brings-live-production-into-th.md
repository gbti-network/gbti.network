SavePoint Station Manager v1.91.0 substantially expands DJ Mode with two new ways to take over a running station: Manual Play for selecting tracks directly from the library, and Studio for producing live video broadcasts from the browser.[^1]

Studio borrows the familiar scenes-and-sources model used by production tools such as OBS,[^2] combining cameras, screen or application capture, images, text, station components, and SavePoint’s existing Main Canvas. Modern browser screen-capture APIs make this kind of direct display and window sharing possible without a separate production application.[^3]

The release goes further with programmable track chat, randomized playlist slots, audio-only MP3/AAC streams, improved chat tools, and several fixes for long-running broadcasts.
