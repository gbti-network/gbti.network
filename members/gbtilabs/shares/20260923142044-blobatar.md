*Blobatar* is an open-source avatar generator that turns any string, such as a username, email address, ID, or Gravatar hash, into a consistent geometric “blob” face. It works without accounts, uploads, or a database and can be used through JavaScript frameworks, a CLI, or a simple HTTP endpoint.

It is especially useful as a lightweight alternative or fallback to *Gravatar*. Existing Gravatar-style URLs can be adapted to Blobatar while keeping the same hash-based approach. The project was created by Alain, who publishes it as an MIT-licensed open-source project rather than a commercial service.
